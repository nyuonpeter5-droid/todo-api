# Todo REST API (Node.js & Express)

A RESTful backend service built with Node.js and Express for managing Todo items with full CRUD operations, input validation, and proper HTTP status code handling.

## Learning Objectives Achieved
- Created an API project using Node.js and the Express framework.
- Implemented RESTful `GET`, `POST`, `PUT`, and `DELETE` endpoints.
- Handled query parameter filtering (`?state=...`).
- Implemented strict input validation returning appropriate HTTP client errors (`400 Bad Request`, `404 Not Found`).
